# Проверка перед публикацией

## Что проверено

В Chromium с эмуляцией размеров и touch проверены обе языковые версии всех восьми экранов:

- 320×568, 360×800, 390×844, 430×932;
- 768×1024, 820×1180, 1024×768;
- 1366×768, 1920×1080;
- горизонтальный телефон 844×390.

Всего 160 состояний. После исправлений нет обнаруженных выходов основных элементов за границы экрана и ошибок JavaScript. Исходный прогон выявил 14 проблемных состояний на трёх экранах; после правок все 60 состояний этих экранов проверены повторно. Итоговые размеры элементов сохранены в `responsive-audit.json`.

Отдельно проверены реальные действия при 320×568:

- Открытие письма, возврат к списку и форма написания сообщения.
- Открытие папки автора одним касанием, загрузка документа и уменьшенные поля документа.
- Доступность принятия манифеста.
- Play/pause по центру, переключение назад/вперёд, естественное завершение записи с запуском следующей.
- Русский заголовок «Городской бестиарий», отсутствие удалённой подписи, открытие досье.
- Работа дождевого плеера и favicon из `dist/`.
- Сохранение времени после полного закрытия Chrome и повторного открытия того же отдельного тестового профиля.

Автоматические проверки: локальные ссылки и контент, HTTP byte ranges, сохранение/возобновление таймера, синтаксис JS. Все прошли.

## Что подготовлено к выкладке

- Иконки вкладки 32/48 px, apple-touch-icon 180 px и favicon.ico из присланного логотипа.
- H.264/AAC-копия стартового видео с faststart и изображением до начала воспроизведения.
- Отдельная сборка `dist/`, не содержащая архивов исходников и неиспользуемых оригиналов медиа.
- Все известные тексты доступны в RU/EN и разложены по разделам; генерируемые каталоги отделены от редактируемых материалов.

## Остаточные проверки перед окончательным запуском

Эмуляция Chromium не заменяет физические устройства и другие движки. Safari/iPhone и Firefox отдельно не проверялись. На реальном телефоне полезно подтвердить воспроизведение, клавиатуру, жесты и чтение длинных текстов.

Субтитры Алекса функциональны, но их оценочный тайминг не прошёл ручную построчную сверку с записью. Редакторская связь записей дождя с текстами сделана по названиям и настроению, как согласовано.

Хостинг ещё не выбран и сайт не опубликован. `dist/` занимает около 219 MiB; крупнейший файл — 10-минутный стартовый фильм, 79.1 MiB (83 МБ). До переноса нужно проверить лимит размера файла, MIME-типы, HTTP Range и фактическую скорость загрузки на выбранной площадке. Если лимит не позволяет, видео выносится на отдельное медиа-хранилище.

К тестовой онлайн-выкладке сборка подготовлена. Финальный запуск требует проверки на реальном телефоне, просмотра материалов автором и проверки хостинга; гарантии работы на каждом существующем устройстве этот аудит не даёт.

## Сжатие стартового видео для GitHub

Стартовый файл повторно сжат из оригинального MOV: H.264, yuv420p, 960×720, два прохода с целевым битрейтом 950 кбит/с; AAC 128 кбит/с. Длительность — 610.195 с, исходник — 610.208 с (разница контейнерного округления менее 0.02 с). Звук сохранён. Размер файла — 82 929 815 байт, меньше 100 MiB. Проверены полное декодирование без ошибок, наличие аудио и faststart (moov перед mdat). Кадр на 30-й секунде сравнен с оригиналом: детализация мягче, пропорции и композиция сохранены. Старый исходный MOV не изменён.
