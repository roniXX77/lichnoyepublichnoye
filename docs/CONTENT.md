# Где редактировать тексты

База данных сайту не нужна. `content/ru/` и `content/en/` — основные редактируемые материалы. Имена и номера связывают одинаковые произведения между языками.

| Раздел | Файлы | Как редактировать |
| --- | --- | --- |
| Почта агента | `content/{ru,en}/mail.json` | Папки `sent`, `drafts`; у письма поля `from`, `to`, `subject`, `body`. Переносы строк — `\n`. |
| Дождь | `content/{ru,en}/rain.json` | `main` — вступление, ключи `1`–`9` — тексты. |
| Алекс | `content/{ru,en}/alex.json` | `main` — история с озвучкой, остальные ключи — произведения в досье. Пропущенный №4 соответствует оригинальному PDF. |
| Субтитры Алекса | `content/{ru,en}/alex-subtitles.json` | `start` и `end` в секундах, `text` — показанная фраза. Тайминг сейчас приблизительный. |
| Автор | `content/{ru,en}/author-main.html`, `author-1.html` … `author-15.html` | HTML сохранён ради форматирования оригиналов; меняется содержимое `<body>`. Общая адаптация — `css/document.css`. |
| Турист | `content/{ru,en}/tourist-1.html` … `tourist-24.html` | Простой HTML: текст внутри `<div>`. Номер соответствует ID рейса. |
| Интерфейс и манифест | `content/translations.js` | Словарь: русский текст → английский. |
| Подписи экрана Алекса | `JS/akvalangistAlex.js` | Два небольших объекта `labels` для EN/RU. |

После правки JSON выполнить:

```sh
python3 scripts/build-content.py
python3 scripts/check.py
```

`content/mail.js`, `content/rain.js`, `content/alex.js` — автоматически собранные браузерные копии. Их вручную редактировать не нужно. Это позволяет загружать литературу без сервера приложения и базы данных.

`content/rain-map.json` задаёт, какой текст появляется с каждой из десяти аудиодорожек; текущее соответствие — один текст на одну запись. `content/alex-files.json` связывает рисунки с досье и задаёт кадрирование. После их изменения также нужен `build-content.py`.

`content/source/` — архив присланных оригиналов PDF и извлечённого текста. Он не попадает в `dist/`. Старые дубликаты авторских HTML удалены; канонические русские документы сохранены в `content/ru/`.

Все ранее присланные произведения подключены. Новые материалы можно присылать с названием раздела, языком и номером/названием произведения: существующие связи обновляются или добавляются по этим идентификаторам.

Важно: импорт из PDF и пересчёт субтитров выполняются только при намеренном обновлении исходника. Они перезаписывают соответствующие редактируемые файлы.
