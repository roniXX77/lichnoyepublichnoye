# lichnoyepublichnoye

Личное публичное / Personal Public.

Статический литературный сайт: стартовый фильм, выбор персонажа, автор, почта агента, Алекс, дождь и турист. Установка JavaScript-зависимостей не нужна.

## Локальный запуск

```sh
python3 scripts/serve.py
```

Открыть `http://127.0.0.1:8000/`. Сервер поддерживает HTTP Range: перемотка видео и озвучки работает. Обычный `python3 -m http.server` эту возможность не предоставляет.

## Тексты и структура

[Памятка по редактированию](docs/CONTENT.md) описывает каждый файл. Основные материалы находятся в `content/ru/` и `content/en/`. Оригиналы присланных PDF сохраняются в `content/source/` и не публикуются.

- `main.html`, `index.html`, `choicePage/` — экраны и навигация.
- `JS/` — контроллеры персонажей; `JS/shared/` — язык и общий таймер.
- `css/` — стили экранов, общий интерфейс и адаптация авторских документов.
- `content/` — редактируемые материалы и генерируемые JS-каталоги.
- `imagesAndVideos/` — медиа, рисунки и иконки вкладки из LP_logo.
- `scripts/` — локальный сервер, сборка контента, проверки и подготовка публикации.
- `tests/` — проверки таймера и HTTP Range.

После изменения JSON:

```sh
python3 scripts/build-content.py
python3 scripts/check.py
```

## Язык и время

При первом посещении открывается EN; выбор EN/RU сохраняется. Выход из персонажа возвращает к стартовому видео.

Таймер хранится в `localStorage` под ключом `personal-public:elapsed-ms` и переживает полное закрытие вкладки и браузера. Считается только видимое время внутри персонажей. На стартовом экране, в меню, в скрытой вкладке и при закрытом сайте время не прибавляется. В приватном режиме и после очистки данных браузера значение может исчезнуть.

Хранилище привязано к адресу сайта. `localhost:5500`, `127.0.0.1:8000` и будущий публичный домен имеют независимые счётчики. Перенос проекта на другой адрес не переносит накопленное время.

## Медиа и персонажи

Стартовый ролик подготовлен в H.264/AAC: `intro.mp4` весит 79.1 MiB (83 МБ), разрешение 960×720. Он сжат из исходного MOV в два прохода: видео 950 кбит/с, AAC 128 кбит/с. Исходный файл — около 893 MiB. Оригинал MOV сохранён и исключён из публикации. Изменения длительности или монтажа не вносились. Если браузер блокирует звук при входе, доступна кнопка `play sound` / `включить звук`.

Дождь: 10 записей, кнопки назад/пауза/вперёд, автоматический следующий трек; после последнего начинается первый. Соответствие текстов записям редактируется в `content/rain-map.json`.

Алекс: видео зациклено, отдельная озвучка EN/RU, перемотка и пропуск к досье через тёмное затухание. При смене языка сохраняется относительная позиция озвучки или открытое дело. В исходных PDF нет №4: нумерация сохранена. Рисунки смешаны, параметры кадрирования — в `content/alex-files.json`.

Субтитры рассчитаны приблизительно по звучащим участкам и длине фраз. Точный тайминг редактируется в `content/{ru,en}/alex-subtitles.json`. Пересчёт исходной оценки: `python3 scripts/build-alex-subtitles.py` (нужны ffmpeg/ffprobe), затем сборка контента.

Почта является частью художественного интерфейса. На телефоне папки открываются кнопкой Mail/«почта». В Compose редактируются адресат, тема и текст; Send добавляет письмо в Sent. Новые сообщения, изменения черновиков и перемещения писем живут в памяти текущего экрана; внешняя почта не отправляется.

## Проверки и публикация

```sh
python3 scripts/check.py
node --test tests/*.test.cjs
python3 tests/serve.test.py
python3 scripts/package-site.py
```

Последняя команда пересобирает `dist/` — папку для статического хостинга. Она содержит только используемые материалы: без PDF, исходных MOV, неиспользуемого dandelion.mov, служебного кода и дубликатов. Вручную `dist/` редактировать не нужно.

[Результаты проверки](docs/QA.md) содержат проверенные размеры экранов, сценарии и ограничения. Сайт опубликован через GitHub Pages. На публичном адресе проверены воспроизведение, загрузка контента и HTTP Range для перемотки; при переносе на другую площадку эти возможности проверяются повторно.

## GitHub Pages

Репозиторий: https://github.com/roniXX77/lichnoyepublichnoye

Адрес публикации: https://lichnoyepublichnoye.art/

При `git push` в ветку `main` workflow `Publish lichnoyepublichnoye` проверяет файлы, собирает `dist/` и публикует её в GitHub Pages. Редактировать нужно исходные файлы; `dist/` не хранится в Git. Оригиналы больших MOV, архивные PDF и исходник логотипа также исключены из Git.

Имена файлов дождевых записей используют постоянные ID (`track-01.m4a` и т. п.); удаление записи не перенумеровывает остальные файлы. Отображаемые названия остаются в HTML. Это исключает различия нормализации кириллицы при переносе с macOS на Linux.

Свой домен можно добавить позднее в Settings → Pages → Custom domain. Файл CNAME до выбора домена не нужен.

На узких экранах турист показывает все 24 рейса вертикальными карточками, на широких — исходное табло с переключением страниц. Медийные кнопки рисуются SVG и не зависят от emoji-шрифта. Белая бумага рисунков Алекса убирается альфа-фильтром SVG вместо смешивания с фоном; сканы не изменены.

Стартовый фильм запоминает последний момент нажатия «сделать паузу» в `sessionStorage` текущей вкладки. При выходе из персонажа фильм возвращается к этому моменту, а пауза/переход к выбору доступны сразу. Первые 16 секунд ожидания остаются только для первого входа без сохранённой паузы.

Дождь: ползунок позволяет перематывать мышью, касанием или клавиатурой, сохраняя состояние паузы. Десять оставшихся записей связаны с десятью текстами без повторов. Удалены прежние позиции 2, 9 и 10; локальные оригиналы сохранены в игнорируемом архиве `content/source/rain-audio-removed/`.

В сборке JS/CSS получают хеш в URL, чтобы после обновления загружались согласованные версии интерфейса и данных. Пользовательский домен настроен в GitHub Pages; workflow не изменяет его настройки.
